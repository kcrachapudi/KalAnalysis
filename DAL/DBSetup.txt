# To Setup Migrations
1. From flask venv terminal set the flask app variable to the runnable file, in our example run.py
    SET FLASK_APP=run.py
2. Set the Initial Migrations - This may not be required for later migrations
    flask db init
3. Setup the Migrations 
    flask db migrate
4. Move the Migrations to the db
    flask db upgrade


# To perform Database tasks like Seeding
1. Open Python terminal
2. import run -> Here run.py is the runnable script
3. If this opens the Flask Website close it with Ctrl-C
4. Call the method that needs to be run on the Database
    Ex: run.DBSeed()


# To Call Functions from Script Files
1. Open Python terminal
2. import Exec -> Here Exec.py is the runnable script
3. If this opens the Flask Website close it with Ctrl-C
4. Call the function that needs to be run
    Ex: Exec.Execute()
